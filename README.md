# 课程表 App（Android）

一款简洁美观的安卓课程表应用，用 Kotlin + Jetpack Compose 开发，**纯本地、不联网**。

## 功能

- ✅ 周课表网格视图（星期 × 节次，今天高亮，可切换周数）
- ✅ 日视图 + 今日课程列表
- ✅ 课程增删改：名称 / 老师 / 教室 / 星期 / 节次 / 周次 / 颜色
- ✅ 单双周、自定义周次
- ✅ 同课合并（同一天、同名同老师且节次相邻的课自动连成一块）
- ✅ 节次时间表自定义、当前课高亮与倒计时
- ✅ **粘贴文本导入**（复制任意课表文字，一键识别）
- ✅ **教务系统导入**（JS 适配脚本框架，可扩展各学校）
- ✅ **WakeUp 口令导入**（见下方说明）
- ✅ 文件导入：CSV / HTML 网页课表 / Excel(.xlsx)
- ✅ 上课提醒、次日课程提醒
- ✅ 休息日与调休日设置（休息日标红）
- ✅ 毛玻璃界面、主题色、深浅色、自定义背景、课程格子外观精细调节
- ✅ 数据备份导出/导入（JSON）
- ✅ 桌面小组件（今日课程）

## 导入课表

### 方式一：粘贴文本导入（推荐，最省事）

在任意地方复制课表文字（教务系统网页、聊天记录等），在本 App 点「导入 → 粘贴文本导入」即可。
每行一门课，例如：

```
高等数学 张三 周一 1-2节 教学楼A101
大学英语 李四 周二 3-4节 1-16周 B202
体育 王五 周三 5-6节 单周 操场
```

会尽力识别课程名、老师、地点、星期、节次、周次。

### 方式二：教务系统导入（适配脚本）

内置 JS 脚本引擎（QuickJS），通过**适配脚本**兼容各学校教务系统。

- 在「导入 → 教务系统导入」选择学校适配器，输入学号密码即可；
- 适配脚本用 JavaScript 编写，API 见 App 内示例脚本注释；
- 支持从远端仓库更新适配脚本（仓库为 JSON 数组，字段：`id` / `name` / `script`）；
- 也可在 App 内直接编辑脚本，保存后立即使用。

**脚本 API 摘要：**

```javascript
async function getSchedule(params) {
  // params.username / params.password
  const res = await http.postForm('https://jw.example.edu/login',
                                  { username: params.username, password: params.password });
  // http.get / http.post / http.postForm 均返回 { status, body }
  // 还有 log() / md5() / sha1() / base64.encode/decode
  setTimeTable([{ node: 1, start: '08:00', end: '08:45' }]);  // 可选：作息时间
  setSemesterStart('2026-09-01');                             // 可选：开学日期
  done([{ name: '高等数学', teacher: '张三', room: 'A101',
          day: 0, startNode: 1, step: 2, weeks: '1-16' }]);
}
```

> 说明：适配脚本需要针对每个学校单独编写（各校教务系统差异很大）。仓库内置的是示例脚本，供你参照修改。

### 方式二：WakeUp 课程表口令导入

如果你用 WakeUp 课程表，可以在其中「分享课表」复制口令，然后在本 App 点「导入 → WakeUp 口令导入」粘贴。

> ⚠️ **重要说明**：该功能通过调用 WakeUp 的服务器接口换取课表数据，属于对第三方服务的非公开接口调用。
> 1. 该接口随时可能变更导致失效，**不保证长期可用**；
> 2. 除该功能外，本 App 其余功能完全离线，不需要网络；
> 3. 使用时请遵守 WakeUp 的用户协议。如介意，请使用其它导入方式。

### 方式三：文件导入

支持 CSV、HTML 网页课表、Excel(.xlsx)。

CSV 格式（每行一门课，英文逗号分隔 8 列）：

```
课程名,老师,教室,星期(1-7),开始节,结束节,周次类型,自定义周次
```

示例：

```
高等数学,张三,教学楼A101,1,1,2,每周,
大学英语,李四,教学楼B202,3,3,4,单周,
体育,王五,操场,5,7,8,自定义,1-8,10-16
```

- 星期：1=周一 … 7=周日
- 周次类型：`每周` / `单周` / `双周` / `自定义`
- 自定义周次：如 `1-8,10-16`

## 一、如何打开运行（重要，请按顺序做）

1. 打开 **Android Studio**（Rabbit 2026.2 版本）。
2. 菜单栏选择 `File → Open`，选中本文件夹（`CourseSchedule`），点确定。
3. 等待 Android Studio **首次同步（Sync）** 完成。第一次会自动下载 Gradle 和依赖库，**可能需要几分钟甚至更久**（取决于网速），请耐心等待，不要中途关闭。
4. 如果提示下载 **Android SDK Platform 36** 或其它 SDK 组件，点 **OK / Accept** 让它自动下载。
5. 顶部工具栏选择一个**模拟器**（或连接一台安卓手机并开启 USB 调试），点击绿色的 **▶ Run** 按钮。
6. 手机上就能看到并操作课程表了。

> 首次构建慢是正常的，之后就会快很多。

## 二、如果提示「gradle-wrapper.jar 缺失」

本项目的 Gradle wrapper 需要联网下载一次。如果 Android Studio 提示缺少 `gradle-wrapper.jar`：

- 方法一：直接**双击运行**项目根目录下的 `修复wrapper.bat`，它会自动下载，然后再回到 Android Studio。
- 方法二：在 Android Studio 里点 `File → Sync Project with Gradle Files`，按提示处理。

## 三、快速上手

1. 点击右下角 **「添加课程」**，填课程名、选星期和节次即可，其它可留空。
2. 点课表里的**课程色块**可编辑或删除。
3. 顶部 **← 第 N 周 →** 可切换周数。
4. 右上角 **⬇ 导入** 图标：从文件导入课表。
5. 右上角 **⚙ 设置** 图标：改周数、节次时间、开学日期、上课提醒。

## 四、CSV 导入格式（推荐，最稳定）

> HTML / Excel 导入为「尽力解析」，对标准教务课表效果好；复杂表格建议转成 CSV 或直接粘贴文本导入。

## 常见问题

| 问题 | 解决办法 |
|------|----------|
| 首次同步一直转圈 | 正常，下载依赖需要时间；确认能上网，耐心等待 |
| 提示 SDK 缺失 | 按提示点 Accept 下载 SDK Platform 36 |
| 提示 JAVA 版本问题 | 菜单 `File → Settings → Build Tools → Gradle`，把 Gradle JDK 设为 Studio 自带的 JDK |
| 通知没收到 | 检查设置里是否开启「上课提醒」，并在系统设置里允许本 App 的通知权限 |
| 提醒需要开学日期 | 在「设置 → 学期第一天」填开学日期（如 2026-09-01），否则默认以本周一为第 1 周 |

## 项目结构

```
app/src/main/java/com/example/courseschedule/
├── MainActivity.kt          # 入口 + 页面导航 + 背景/毛玻璃
├── data/                    # 数据模型 + 本地 JSON 存储
├── ui/                      # 界面（主题、课表、编辑、设置、导入）
├── import/                  # 文本 / CSV / HTML / Excel / WakeUp 口令解析
├── notification/            # 上课提醒、次日提醒
└── widget/                  # 桌面小组件
```

数据保存在手机应用私有目录的 `schedule_data.json`，卸载或清除数据会删除。
