# 课程表 App（Android）

一款苹果风格（iOS 设计规范）的安卓课程表，用 Kotlin + Jetpack Compose 开发，**纯本地、不联网**。

## 功能

- ✅ 周课表网格视图（星期 × 节次，今天高亮，可切换周数）
- ✅ 课程增删改：名称 / 老师 / 教室 / 星期 / 节次 / 周次 / 颜色
- ✅ 单双周、自定义周次
- ✅ 节次时间表自定义（每节课几点到几点）
- ✅ 文件导入：CSV / HTML 网页课表 / Excel(.xlsx)
- ✅ 上课提醒通知（课前定时提醒）
- ✅ 深色 / 浅色模式自动适配

## 一、如何打开运行（重要，请按顺序做）

1. 打开 **Android Studio**（Rabbit 2026.2 版本）。
2. 菜单栏选择 `File → Open`，选中本文件夹（`CourseSchedule`），点确定。
3. 等待 Android Studio **首次同步（Sync）** 完成。第一次会自动下载 Gradle 和依赖库，**可能需要几分钟甚至更久**（取决于网速），请耐心等待，不要中途关闭。
4. 如果提示下载 **Android SDK Platform 36** 或其它 SDK 组件，点 **OK / Accept** 让它自动下载。
5. 顶部工具栏选择一个**模拟器**（或连接一台安卓手机并开启 USB 调试），点击绿色的 **▶ Run** 按钮。
6. 手机上就能看到并操作课程表了。

> 首次构建慢是正常的，之后就会快很多。

## 二、如果提示「gradle-wrapper.jar 缺失」

本项目的 Gradle wrapper 需要联网下载一次。如果 Android Studio 提示缺少 `gradle-wrapper.jar`：

- 方法一：直接**双击运行**项目根目录下的 `修复wrapper.bat`，它会自动下载，然后再回到 Android Studio。
- 方法二：在 Android Studio 里点 `File → Sync Project with Gradle Files`，按提示处理。

## 三、快速上手

1. 点击右下角 **「添加课程」**，填课程名、选星期和节次即可，其它可留空。
2. 点课表里的**课程色块**可编辑或删除。
3. 顶部 **← 第 N 周 →** 可切换周数。
4. 右上角 **⬇ 导入** 图标：从文件导入课表。
5. 右上角 **⚙ 设置** 图标：改周数、节次时间、开学日期、上课提醒。

## 四、CSV 导入格式（推荐，最稳定）

每行一门课，用英文逗号分隔 8 列：

```
课程名,老师,教室,星期(1-7),开始节,结束节,周次类型,自定义周次
```

示例（用「记事本」新建文件，保存为 `.csv`，**编码选 UTF-8**）：

```
高等数学,张三,教学楼A101,1,1,2,每周,
大学英语,李四,教学楼B202,3,3,4,单周,
体育,王五,操场,5,7,8,自定义,1-8,10-16
```

- 星期：1=周一 … 7=周日
- 周次类型：`每周` / `单周` / `双周` / `自定义`
- 自定义周次：如 `1-8,10-16`

> HTML / Excel 导入为「尽力解析」，对标准教务课表效果好；复杂表格建议转成 CSV 再导入。

## 五、常见问题

| 问题 | 解决办法 |
|------|----------|
| 首次同步一直转圈 | 正常，下载依赖需要时间；确认能上网，耐心等待 |
| 提示 SDK 缺失 | 按提示点 Accept 下载 SDK Platform 36 |
| 提示 JAVA 版本问题 | 菜单 `File → Settings → Build Tools → Gradle`，把 Gradle JDK 设为 Studio 自带的 JDK |
| 通知没收到 | 检查设置里是否开启「上课提醒」，并在系统设置里允许本 App 的通知权限 |
| 提醒需要开学日期 | 在「设置 → 学期第一天」填开学日期（如 2026-09-01），否则默认以本周一为第 1 周 |

## 六、项目结构

```
app/src/main/java/com/example/courseschedule/
├── MainActivity.kt          # 入口 + 页面导航
├── data/                    # 数据模型 + 本地 JSON 存储
├── ui/                      # 界面（主题、课表、编辑、设置、导入）
├── import/                  # CSV / HTML / Excel 解析
└── notification/            # 上课提醒
```

数据保存在手机应用私有目录的 `schedule_data.json`，卸载或清除数据会删除。
